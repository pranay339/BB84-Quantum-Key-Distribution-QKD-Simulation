Developed a Python-based simulation of the BB84 Quantum Key Distribution protocol to demonstrate the fundamentals of quantum cryptography.
Simulates secure communication between two parties (Alice and Bob) through quantum key exchange.
Generates random bits and quantum bases to create and transmit qubits securely.
Detects potential eavesdropping attempts by analyzing the error rate in the generated key.
Compares measurement bases to produce a shared secret key for secure communication.
Includes a simple message encryption and decryption feature using the generated quantum key.
Provides a dashboard displaying key generation statistics, error rates, and security status.
Visualizes communication results through graphs to help understand the impact of attacks and transmission errors.
